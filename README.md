# Hit and Blow

ブラウザで動作する Hit and Blow ゲームです。PC とスマホの両方に対応し、次の 3 モードを提供します。

- 1人プレイ
- 1端末で2人プレイ
- 2端末オンライン対戦

オンライン対戦はアカウント不要で、部屋コードだけで参加できます。

## 概要

- フロントエンド: Next.js + TypeScript
- リアルタイム通信: Socket.IO
- 実行方式: Next.js App Router + custom Node server
- 保存方針:
  - 対局履歴は `sessionStorage` に保存
  - オンラインのルーム状態はサーバメモリに保存
  - ブラウザを閉じると履歴は消える
  - サーバ再起動時にオンライン対局は保持されない

## ルール

### 共通

- 秘密列は毎ゲーム完全ランダムで生成されます。
- 設定可能な項目:
  - コード長: `1` から `10`
  - 色数 / 数字数: `1` から `10`
  - 同色あり / なし
  - ターン制限: `1` から `50`、または無制限
  - アシストモード ON / OFF
- `同色なし` の場合は `色数 >= コード長` が必須です。
- `6色以下` では入力・履歴・正解表示を色チップで統一し、`7色以上` では数字表示を使います。
- 秘密列の生成ルールが `同色なし` でも、推理としては同じ記号を重複して入力できます。
- 入力欄は画面最下部に固定表示され、履歴をスクロールしていても操作位置は変わりません。
- 入力スロットは左から順に埋めるだけでなく、任意の位置をクリックして直接入力できます。

### 1人プレイ

- プレイヤーはひとりです。
- 1 回の推理が 1 ターンです。
- ターン制限内に秘密列を当てればクリアです。

### 1端末で2人プレイ

- 1台の端末を共有し、`プレイヤー1` と `プレイヤー2` が交互に推理します。
- 2人は同じ秘密列を解きます。
- 1 ラウンド内で両者が 1 回ずつ推理します。
- 誰かがそのラウンド中に正解しても、もう片方には同ラウンド内の最終手番が与えられます。
- 同じラウンドで両者が正解した場合は引き分けです。

### 2端末オンライン対戦

- アカウント作成は不要です。
- 6 文字の部屋コードで参加します。
- 最大 2 人まで参加できます。
- 2 人そろうと対局を開始します。
- ルールは `1端末で2人プレイ` と同じで、共有の秘密列を交互に推理します。
- 対戦中は相手が現在入力している内容をリアルタイムで確認できます。
- 切断時は 5 分間だけ再接続を待ちます。
- ルームは単一 Node プロセス前提です。

## アシストモード

- アシスト ON の場合でも、対局中に `アシストを表示` ボタンを押したときだけ情報を表示します。
- 表示される内容は、公開済み履歴から計算した次の情報です。
  - 残り候補数
  - 使用済み記号
  - 未使用記号
- 初期候補空間が `100,000` 以下なら、残り候補数を厳密に表示します。
- 初期候補空間が `100,000` を超える場合は、候補数表示を省略し、簡易ヒントのみを表示します。
- アシストは公開済み履歴だけを使い、秘密情報は直接表示しません。

## 履歴

- 対局中の履歴は、従来の入力欄位置に積み上がる形で表示されます。
- 対局中の履歴エリアは固定高さで、件数が増えた場合は内部スクロールします。
- ターン制限がある場合は、将来の履歴が入る予定枠も表示し、残り手数を確認できます。
- 入力欄は履歴とは分離され、画面最下部の固定ドックから常に操作できます。
- 対局中は全ての推理履歴を画面上で確認できます。
- 終了した対局は `/history` で見られます。
- 履歴はブラウザセッション限定です。
- ブラウザを閉じると履歴は消えます。

## 画面構成

- `/`
  - 設定画面
  - モード選択
- `/play/solo`
  - 1人プレイ
- `/play/local`
  - 1端末で2人プレイ
- `/play/online`
  - オンラインロビーと対戦画面
- `/history`
  - セッション履歴

## 開発環境

### 前提

- Node.js 22 以降を推奨
- npm 10 以降を推奨

### セットアップ

```bash
npm install
```

### 開発サーバ

```bash
npm run dev
```

`http://127.0.0.1:3000` でアクセスできます。

### 本番ビルド

```bash
npm run build
npm run start
```

## テスト

### ユニットテスト

```bash
npm test
```

対象:

- Hit / Blow 計算
- 設定バリデーション
- 秘密列生成と推理入力の重複ルール
- ラウンド進行
- アシスト表示の切り替え

### E2E テスト

```bash
npm run test:e2e
```

Playwright の簡易スモークテストを用意しています。

## v1 の制約

- 単一サーバインスタンス前提
- 永続 DB は使わない
- ランキングなし
- 観戦モードなし
- チャットなし
- 外部共有用の招待 URL なし
- サーバ再起動時の対局復元なし

## 主な実装ファイル

- `server.ts`
  - Next.js custom server と Socket.IO 起動
- `src/server/room-manager.ts`
  - オンライン対戦のルーム管理
- `src/lib/game/engine.ts`
  - 乱数生成、Hit / Blow 判定、ラウンド進行、アシスト計算
- `src/components/`
  - 設定画面、各プレイ画面、履歴画面
